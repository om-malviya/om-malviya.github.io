Search Typeahead

C++20 · Redis · PostgreSQL

A low-latency search-suggestion service over a real 300k+ row Wikipedia Pageviews dataset. A hand-written Trie serves ranked top-10 prefix matches, fronted by a Redis cache sharded across 3 nodes via a consistent-hash ring. A batched writer cuts DB write pressure; p50/p95/p99 latency and cache-hit rate benchmarked.
